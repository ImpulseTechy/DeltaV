# DeltaV – Engineering Career Roadmaps (V1)

> **Vision:** Build the world's best interactive engineering roadmap platform for Electronics, Embedded Systems, Robotics, IoT, Automation, VLSI, and Space Engineering.

Unlike traditional course platforms, DeltaV focuses on **career roadmaps** rather than isolated courses. Every roadmap is composed of reusable **Skills**, where each skill contains learning resources, projects, simulations, quizzes, and interview preparation.

# DeltaV Architecture Philosophy

DeltaV is not a collection of courses.

It is a **Career Graph Platform**.

## Career Roadmaps

Career Roadmaps define **what students want to become**.

Examples:

- Embedded Systems Engineer
- IoT Engineer
- Robotics Engineer
- PCB Design Engineer

---

## Skills

Every roadmap is built from reusable **Skills**.

Examples:

- UART
- ESP32
- FreeRTOS
- MQTT
- KiCad

A Skill exists only once and can be reused across multiple career roadmaps.
